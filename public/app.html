Node.js: runs node <file> with the PORT env auto-filled. PHP: needs pkg install php, served via php -S 127.0.0.1:PORT. Static: needs python, serves a folder via python3 -m http.server. Go: needs Go, runs go run . in the project folder with the PORT env auto-filled.

Akses per website: Stay Local = hanya bisa dibuka dari HP/Termux (localhost), Tunneling = dapat URL publik Cloudflare (Quick tanpa akun, atau Named pakai token). Klik Atur di kolom Akses untuk memilih mode Quick/Named dan token.
